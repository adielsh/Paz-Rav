# 🎮 ONBOARDING FUN ZONE

אתר הסברה משחקי שמלמד את **פז רב** לעומק — 8 עולמות, מיני־משחקים, כוכבים, XP וקרב בוס.
מתאים לילדים ולמבוגרים; בסוף המסע תבינו את הארכיטקטורה מספיק טוב כדי לקרוא את
`docs/ARCHITECTURE.md` בהנאה.

## איך משחקים

פשוט פותחים את `index.html` בדפדפן (דאבל־קליק). אין build, אין שרת, אין תלויות —
HTML + CSS + JS ונילה שעובדים מ־`file://`.

```bash
# או, אם בא לכם שרת:
npx serve "ONBOARDING FUN ZONE"
```

ההתקדמות (כוכבים, XP, עולמות פתוחים) נשמרת ב־localStorage של הדפדפן.
